# Batch Tinify

Batch Tinify est un script Python simple permettant de redimensionner puis compresser automatiquement des images à l'aide de l'API Tinify.

- Redimensionne les images pour que la plus grande dimension soit de 800 pixels.
- Compresse les fichiers `jpg`, `jpeg` et `png`.
- Place les fichiers optimisés dans un dossier de sortie.
